# Alarm Investigation and Procedure Guidance Copilot

> Senior Software Engineer – Copilot Integration assignment.
> **Selected use case:** Alarm Investigation and Procedure Guidance Copilot.

An assistant that investigates industrial plant alarms. It pulls alarm data through a
candidate-built **MCP server** and procedure guidance through **document RAG**, then
combines both into one grounded answer with citations and a visible tool trace.
